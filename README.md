A tiny, deterministic program for the make.fun competition
"Fortune Cookie Wisdom for Developers". It writes exactly one
fortune-cookie line for a software developer to
`/output/entry.txt`:

> The bug you seek is not in the code you wrote today, but in the
> code you were sure needed no test.

The program checks this competition's 1–120 character gate itself
before writing. No network, no randomness: every run produces the
same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
